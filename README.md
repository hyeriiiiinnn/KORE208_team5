# 한국어 정보처리 팀 프로젝트

## 주제
정치 뉴스 기사 크롤링 및 형태소 분석을 통해  
2025년 제21대 대선과 관련하여 언론에서 각 후보자에게 구성된 주류 담론을 파악함으로써,
언론 담론 및 언어가 당선 가능성 예측에 어떻게 기여할 수 있는지 탐색한다.


## 팀원
- 노형래
- 민혜린
- 추소영
- Zhang Mei

## 폴더 구조
1. crawling : 기사 데이터 크롤링 코드 및 결과 파일을 담은 폴더입니다.
2. kiwi VS mecab : 형태소 분석기 선택 과정에 있어 샘플 작업을 수행, kiwi로 선정하였습니다.
3. data preprocessing : 사용자 사전 정의 및 불용어 처리 등의 전처리를 수행하였습니다.
4. TF-IDF : TF 분석, TF-IDF 분석, TF-IDF 기반 코사인 유사도 분석 등을 수행하였습니다.
5. word embedding : Word2Vec 기반 워드임베딩을 통해 단어 클러스터 및 의미망 등을 분석하였습니다.
6. In-sentence co-occurrence validation : 특정 정치인 이름과 특정 단어(들)이 동시에 출현하는 문장을 랜덤으로 n개 추출하는 코드를 작성하여, 앞선 텍스트 마이닝 기법들에서 도출된 결과를 실제 데이터 관찰을 통해 맥락을 파악하고 검증하고자 했습니다.
7. tutorial : 발표 중 진행할 크롤링 튜토리얼 폴더입니다.
